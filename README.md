# BookyMark

### in progress since (oct 2, 2026).

## what is it?

BookyMark is a very simple Bookmark Manager that only have Collection and without a Tags.

im making these just to drop a link that i discover that im interested in but sometimes forgot to saves it.

## what you can do?

- create, update, delete, favorite for Bookmark, Collection and Notes
- see all your Bookmark and Collection with image and icon
- search by title
- filter by favorite, created and updated at
- order by name
- see all the totals of your saved Bookmark and Collection

## tech stack

- Blazor (.NET 10)
- SQLite (using EF Core)
- LinkMetadata API [LinkMetadata](https://linkmetadata.com/)
- TailwindCSS

## if you want to use it

- install .NET 10 https://dotnet.microsoft.com/en-us/download
- install Node.js (needed for the Tailwind CLI build)
- clone this project
- restore npm packages:
    ```
    npm install
    ```
